 📒 Python Contact Book

A simple command-line Contact Book application built using Python. This project allows users to store and manage contact information through a menu-driven interface.

 🚀 Features

 ➕ Add new contacts
 📋 View all contacts
 🔍 Search contacts by name
 ✏️ Update existing contact details
 🗑️ Delete contacts
 🚪 Exit the application

 🛠️ Technologies Used

 Python 3
